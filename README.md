Ultimate goal: Build a working crop health detector as a continuation of the agriculture equity distributor project. 
SoilSensor will track humidity, temperature, soil moisture, and etc. to track when crops need water and place into csv data format to be used in divider

Parts list:
1. Custom PCB designed on KiCad
2. Ardunio 33 BLE Sense
3. SHT40 Temperature Humidity Sensor Module
4. SEN0193 Analog Capacitive Soil moisture Sensor
5. Breadboard, M-F M-M jumper cables, 5.1k and 330 resistors, 100 nF capacitor, LEDs, and other circuit component
6. Soldering equipment for PCB
7. Multimeter for testing   

Softwares:
1. KiCad
2. Arduino IDE
3. Python
